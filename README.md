# «Точка слуха» — сайт центра слухопротезирования

Сайт центра «Точка слуха» в Краснодаре: каталог слуховых аппаратов ReSound и Исток-Аудио,
акции, статьи, адрес с картой и формы записи.

- **Опубликованная версия:** https://lji-dmitriy.github.io/centr-sluha-site/ — временный адрес
  на GitHub Pages, пока у центра нет своего домена. Закрыта от поисковиков: `public/robots.txt`
  и `noindex` в `index.html`.
- **Панель управления** (Directus) пока работает только на компьютере разработчика, в папке
  `panel/`. В репозиторий она не входит.

## Быстрый старт

Нужен Node.js 20.

```bash
npm install
npm run dev         # разработка: http://localhost:5173
npm run build       # сборка в dist/ и готовые HTML-страницы для роботов и превью ссылок
npm run build:fast  # только сборка, без готовых страниц
npm run preview     # посмотреть сборку: http://localhost:4173
npm test            # проверки по собранной версии
npm run deploy      # собрать «как на GitHub Pages», чтобы посмотреть перед отправкой
```

Чтобы сайт брал содержимое из локальной панели, создайте `.env.local` (в репозиторий не попадает):

```
VITE_PANEL_URL=http://localhost:8055
```

Без этой переменной сайт работает на встроенных данных из `src/data/`.

## Как устроено

- React 18, React Router 6, Vite 5, чистый CSS без UI-библиотек. Шрифт Montserrat лежит
  в проекте (`src/assets/fonts`), к Google сайт не обращается.
- У каждой страницы свой файл со скриптом: посетитель скачивает только то, что открыл.
  Основной файл должен весить меньше 260 КБ — это проверяет тест.
- После `vite build` скрипт `scripts/prerender.mjs` открывает каждую страницу в настоящем
  браузере и сохраняет готовый HTML в `dist/<адрес>/index.html`. Его видят поисковые роботы
  и превью ссылок в мессенджерах. Карта Яндекса при этом отключается: её виджет всё время
  что-то догружает, и страница с картой не дожидалась конца загрузки.
- `public/sw.js` — сервис-воркер: сайт открывается без связи и ставится на телефон как приложение.
- `src/components/Seo.jsx` — заголовок, описание, canonical и превью (og:) для каждой
  страницы. Адрес сайта для них приходит из `VITE_SITE_URL`.

### Откуда берётся содержимое

`src/components/ContentContext.jsx` отдаёт страницам каталог, акции, новости, центры,
контакты и мессенджеры:

1. сразу — встроенные данные из `src/data/site.js`;
2. если задан `VITE_PANEL_URL` и панель ответила — данные из панели (`src/lib/panel.js`).

Панель недоступна — сайт остаётся на встроенных данных и работает как обычно.

**Важно:** когда сайт подключён к панели, её содержимое главнее. Правки встроенных данных
нужно повторять в панели, и наоборот.

## Разделы сайта

| Раздел | Адрес | Что внутри |
|---|---|---|
| Главная | `/` | слайдер (тест слуха, сертификат СФР, выезд на дом, аппараты), три предложения, акции, быстрый подбор, аппараты, бренды, форма записи, адрес с картой |
| О центре | `/about` | как проходит подбор, цифры, преимущества, этапы, бренды, частые вопросы |
| Каталог | `/catalog` | разделы по производителям, фильтры, сортировка, по 6 моделей на странице |
| Модель | `/catalog/:slug` | фото, характеристики, запись на примерку, корзина, вкладки «Описание», «Характеристики», «Функции», похожие модели |
| Акции | `/promo`, `/promo/:slug` | список акций и страница акции с формой |
| Адреса центров | `/locations`, `/locations/:slug` | адрес, остановка, часы, как добраться, карта |
| Информация | `/news`, `/news/:slug` | новости и полезные статьи |
| Корзина | `/cart` | отложенные модели к примерке и заявка |
| Контакты | `/contacts` | телефон, почта, мессенджеры, адрес и карта, часы приёма, формы |
| Документы | `/privacy`, `/consent` | политика и согласие на обработку данных |
| 404 | остальное | возврат на главную и быстрые ссылки |

Каталог понимает параметры в адресе: `?cat=resound`, `?form=RIE`, `?feature=аккумулятор`,
`?q=руна`, `?sort=fresh`, `?page=2`. Их можно ставить в ссылки с других страниц.

Сквозные элементы: верхняя полоса (город, часы, телефон), шапка с названием, поиском,
корзиной и кнопкой «Записаться», меню каталога, на телефоне — нижняя панель
«Позвонить / Записаться», кнопка «наверх», подвал.

## Как поменять содержимое

Всё ниже — в `src/data/site.js`. Если сайт подключён к панели, те же правки делаются
в ней — см. «Панель управления».

### Контакты и график

- `SITE` — название, телефон, почта, адрес, часы в шапке, точка на карте страницы «Контакты».
- `CENTERS` — адрес центра, остановка рядом, часы, как добраться, точка на карте.
- `SCHEDULE` — таблица «Часы приёма».

### Каталог

Каждая модель — `item({ ... })` в `CATALOG`:

| Поле | Зачем |
|---|---|
| `slug` | адрес страницы: `/catalog/<slug>` |
| `category` | раздел: `resound` или `istok-audio` (список — `CATEGORIES`) |
| `img` | фото из `public/img/models/` |
| `tag` | метка на карточке: «Рекомендуем», «Новинка» |
| `onHome` | показывать на главной; там помещаются четыре модели |
| `stock` | `pod_zakaz` — «Под заказ», `net` — «Нет в наличии»; пусто — в наличии |
| `price`, `old` | цена и зачёркнутая старая цена; пусто — «Цена по запросу» |
| `short`, `points` | строка и пункты для карточки |
| `attrs` | пять полей в карточке модели: производитель, тип корпуса, мощность, обработка сигнала, число каналов; пустые не выводятся |
| `specs`, `functions` | вкладки «Характеристики» и «Функции» |

Описание модели — в `src/data/descriptions.js` по тому же `slug`. Порядок моделей
в каталоге — порядок в `CATALOG`. Первая модель служит образцом в тестах.

**Фильтры** (`FILTERS`) ищут слово в характеристиках модели: тип корпуса — `BTE`, `RIE`,
`внутриушн`; особенности — `аккумулятор`, `смартфон`, `сверхмощн`. Чтобы модель попала
в фильтр, нужное слово должно стоять в её `specs`, `attrs`, `points` или `short`.

**Цены.** Пока ни у одной модели нет цены, подбор и сортировка по цене и колонка
«Стоимость» в меню каталога скрыты. Появится хотя бы одна цена — они включатся сами.

**Фото модели** — белый фон, 800×600, аппарат по центру. Снимки текущих моделей — от
производителей, с сайта дистрибьютора «Исток-Аудио»; права на них у производителей.

### Акции, новости и остальное

- `PROMOS` — акции: `note` — плашка на карточке («СФР», «0%»), `cover` — картинка,
  `body` — страница акции блоками `{ h }` заголовок, `{ p }` абзац, `{ list }` список,
  `{ note }` сноска мелким шрифтом.
- `NEWS` — новости и статьи (`type: 'news'` или `'article'`).
- `SLIDES`, `OFFERS`, `PICKER` — слайдер, три предложения и быстрый подбор на главной.
- `FAQ`, `STEPS`, `ADVANTAGES`, `STATS`, `BRANDS` — блоки страницы «О центре» и главной.
- `DOCTORS` — специалисты; имена пока вымышленные, фото — в поле `img`.

### Картинки

Общие фото — только со свободной лицензией CC0; источник каждого записан в
`public/photo/ИСТОЧНИКИ.md`. Логотипы и баннеры не рисуем — берём файлы заказчика.

### Мессенджеры

Ссылки задаются в панели, раздел «Мессенджеры». Без панели работает MAX по номеру
телефона, а Telegram, WhatsApp и ВКонтакте стоят заглушками, пока нет ссылок.

## Оформление

Вариант «Тёплый» по образцу европейских сетей слухопротезирования: крупный текст для
пожилых посетителей, на первом экране — фото на всю ширину и белая плашка с текстом.
Центр выбрал его на отдельном сайте примеров (репозиторий `centr-sluha-variants`).

| Цвет | Где |
|---|---|
| `#397c7b` бирюзовый | заголовки, верхняя полоса, ссылки, иконки, подвал, карточки предложений |
| `#8ec8ba` светлая бирюза | точки слайдера, разделители |
| `#e8f4f1` светлая мята | фон разделов, шапок страниц и полей ввода |
| `#e5771e` оранжевый | логотип, все кнопки «Записаться», кнопка карты |
| `#fea254` мягкий оранжевый | плашки акций, метка «Под заказ» |

Цвета заданы переменными в начале `src/styles/global.css`.

## Формы и заявки

- `src/components/RequestForm.jsx` — запись на приём (ФИО, телефон, цель визита,
  комментарий), вопрос сурдологу, обратный звонок; из корзины — заявка на примерку.
  Форма открывается на странице или в окне: `useRequestForm()` → `openForm('visit' | 'ask' | 'call', тема)`.
- С панелью заявка сохраняется в разделе «Заявки с сайта».
- Без панели (сейчас на GitHub Pages) форма сама ничего не отправляет: показывает готовый
  текст заявки и кнопки «позвонить» и «написать письмом».
- Письма о новых заявках на почту центра — в планах: автоматизация Directus (Flow) после
  переезда на сервер. Нужен пароль внешнего приложения от ящика Mail.ru.

## Панель управления

Directus 11.17.4 на SQLite, со своим Node 22 внутри (`panel/runtime`) — на компьютер ничего
ставить не нужно.

- Запуск — `panel/ЗАПУСК ПАНЕЛИ.cmd`, адрес http://localhost:8055.
- Логины и пароли — в `panel/.env`: технический администратор и учётка владельца центра.
  Файл не пересылать и не коммитить.
- Разделы: «Заявки с сайта», «Каталог», «Акции и спецпредложения», «Новости и статьи»,
  «Адреса центров», «Контакты на сайте», «Мессенджеры», «Услуги» (на сайте не выводятся).
- Права: посетители сайта только читают опубликованное и оставляют заявки; владелец центра
  правит содержимое и видит заявки, но не меняет устройство панели.
- `panel/scripts/setup.mjs` (`npm run setup` в папке `panel`, при запущенной панели) создаёт
  разделы и права и переносит туда содержимое сайта. Повторный запуск безопасен: добавляет
  только то, чего нет, и не трогает существующее.
- Инструкция для владельца — `panel/ПАМЯТКА.md`.
- База — `panel/database/panel.db`, загруженные файлы — `panel/uploads/`. Перед крупными
  изменениями делайте копию базы.

## Проверки

`tests/site.spec.js` (Playwright) проверяет:

- главную: слайдер и порядок блоков;
- каталог: страницы, разделы, фильтры и счётчики;
- карточку модели и корзину;
- формы: маску телефона и запасной путь без панели;
- акции, статьи и поиск;
- карту и контакты;
- мета-теги и превью ссылок, готовый HTML для роботов, вес основного файла;
- мобильную вёрстку, размер кнопок под палец и доступность.

- Для тестов сайт собирается без панели — проверяется встроенное содержимое.
- Количество слайдов, акций и моделей, а также модель для проверки тесты берут из данных:
  правки содержимого их не ломают.
- Проверки сортировки и подбора по цене пропускаются, пока у моделей нет цен.
- `npm test` работает и на Windows; при каждой отправке в GitHub те же тесты выполняются
  в Actions (`check.yml`).

## Публикация

- После `git push` в ветку `main` GitHub сам собирает сайт и выкладывает его на Pages
  (`deploy.yml`). Обычно это занимает 3–5 минут, иногда дольше: для готовых страниц
  скачивается браузер.
- Опубликованная версия собирается без панели (`VITE_PANEL_URL` пустой), а адрес сайта
  и подпапка `/centr-sluha-site/` подставляются сами.
- Посмотреть результат заранее — `npm run deploy`, сборка ляжет в `dist/`.
- Прямые ссылки на внутренние страницы работают: у каждой страницы свой готовый HTML,
  а для неизвестных адресов есть `404.html`.

## Перед запуском на своём домене

1. Домен, оформленный на центр, и сервер в России (Ubuntu 24.04, от 2 ГБ памяти).
2. Сайт и панель на сервере с HTTPS, панель — на поддомене. Перенести базу и файлы панели.
3. Обновить Directus до 12.x: в версии 11.17.4 есть известные уязвимости.
4. Новые пароли, двухфакторный вход для администратора; CORS панели — только домен сайта.
5. Защитить форму от спама: проверка телефона на стороне панели и ограничение частоты заявок.
6. Настроить письма о заявках на почту центра.
7. Задать `VITE_SITE_URL` и `BASE_PATH` под домен.
8. Убрать `noindex` из `index.html` и запрет в `public/robots.txt`, добавить сайт
   в Яндекс Вебмастер.
9. Заменить `public/og.png`: сейчас превью ссылки осталось от старого шаблона.
10. Данные центра: реквизиты в политике и согласии, уведомление в Роскомнадзор об обработке
    персональных данных, свои фото центра и специалистов, настоящие имена врачей, цены
    моделей. Проверить характеристики моделей и ближайшую остановку.

## Особенности и ограничения

- Метка на карте Яндекса всегда синяя: бесплатный виджет не даёт сменить её цвет.
- Компоненты выбора даты и времени (`DateInput`, `TimeInput`) в формах сейчас не используются.
- `router.php` в корне — локальный файл для PHP-сервера, в репозиторий не входит. Он отдаёт
  файлы за пределами `dist/`, в том числе `panel/.env` с паролями. Не запускать и не выкладывать
  на сервер, лучше удалить.
